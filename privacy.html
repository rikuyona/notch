プライバシー ポリシー

最終更新日：2026年11月13日

1. 取得する情報

Notch は、利用者が Google アカウントで許可したときに、Google からアクセス トークンとリフレッシュ トークンを受け取ります。求める権限は Google フォトへの写真の追加（photoslibrary.appendonly）のみです。

2. 情報の使いみち

受け取ったトークンは、利用者が Notch にドロップした写真を、利用者自身の Google フォトにアップロードするためだけに使います。Google フォトにある写真・アルバム・プロフィールを読むことはありません。

3. 保存場所

トークンは利用者の PC の中（%USERPROFILE%\.notch）にのみ保存します。作者を含む第三者のサーバーには送りません。

4. 第三者への提供

取得した情報を第三者に提供・販売することはありません。写真の送信先は Google（photoslibrary.googleapis.com）だけです。

5. 連携の解除

Notch の設定で連携を外すか、Google アカウントの「サードパーティのアプリとサービス」から Notch のアクセスを削除すると、以後はアップロードできなくなります。

6. Google API サービスのユーザーデータに関するポリシー

Notch による Google API から受け取った情報の使用と他のアプリへの転送は、限定使用の要件を含むGoogle API サービスのユーザーデータに関するポリシーに従います。
